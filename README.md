# Tafel
## Description:
A small paint program
## Version:
Made in python 3.13.7
Windows release is for 1920x1080
## Controls:
- 1 red
- 2 yellow
- 3 green
- 4 cyan
- 5 blue
- 6 magenta
- 7 white
- 8 gray
- 9 dark gray
- 0 black
- space clear board
- q brush size 1
- w brush size 2
- e brush size 4
- r brush size 8
- t brush size 16
- alt+f4 close
- left click draw
## How to build:
Change the numbers in line 4 to whatever your resolution is (standars is full hd)
Build using pyinstaller with the flag --onefile
